# The Startup Graveyard

Static site (HTML/CSS/JS) driven by a Google Sheet. Deploy the whole folder as-is (Cloudflare Workers/Pages static assets).

- `graveyard.html` is the list page. It MUST be in the deployed folder, otherwise the Graveyard link 404s.
- Connect the Sheet tabs: see SHEET-CONNECT.md (templates in sheet-templates/).
- Buy Me a Beer: see SUPPORT-SETUP.md.
- Add `?debug` to any page address to see which Sheet tabs loaded.
